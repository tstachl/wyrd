# Contributing

Wyrd is pre-alpha software. Prefer small, focused changes that preserve the architecture and documented contracts. Read `AGENTS.md` and `docs/architecture.md` before making changes, then take the guided tour in `docs/design/codebase-tour.md` (reading order, test layout, the `mount` feature matrix, crate-name caveats, and the overloaded vocabulary).

Follow [`docs/collaboration-workflow.md`](docs/collaboration-workflow.md) for the issue, triage, PR, review and merge workflow, including commit and branch conventions and when CI runs. Build and test commands are in `AGENTS.md`. Comments should explain why or how code is used, not narrate each line.
